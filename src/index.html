API SETTINGS

浏览器直连 API

本页直接从浏览器调用你选择的 AI 提供方。官方 DeepSeek 与第三方中转站分别保存各自的 Key，不会互相复用；Key 只保存在当前浏览器的 localStorage 中，不会写入 HTML、仓库文件、URL 或请求历史，但页面脚本与开发者工具仍可读取它，请勿在公用电脑上保存。

API 提供方

官方公开模型为 deepseek-chat / deepseek-reasoner；若账号提供支持图片输入的视觉模型，请填写准确名称。若模型拒绝图片，页面会显示官方返回的真实错误并保留图片，不会自动改用中转站。

官方端点已实测允许来自本地文件的 CORS 预检（Origin: null）；中转站的 CORS 由各自服务商决定，失败时页面会显示真实错误，需改用本机 Node 服务模式或换配置。渠道仅作为本地备注保存，不会写入请求。
